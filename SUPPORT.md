# Support

Where to get help with Equaxis.

## Documentation first

- [README.md](README.md) — quick start, mission control, safety model
- [docs/](docs/) — architecture, policy, memory, evaluation, provider setup
- [CHANGELOG.md](CHANGELOG.md) — what changed between releases

## Getting help

- **Bugs and feature requests**: open a GitHub issue with the
  [bug report](.github/ISSUE_TEMPLATE/bug_report.md) or
  [feature request](.github/ISSUE_TEMPLATE/feature_request.md) template.
- **Security vulnerabilities**: see [SECURITY.md](SECURITY.md) — do not open a public issue.
- **Contributions**: see [CONTRIBUTING.md](CONTRIBUTING.md).
- **pi-web dashboards**: the fork lives in `pi-web/` (see `pi-web/README.md`); dashboard
  questions belong in the same issue tracker, tagged with the dashboard area.

## Scope of support

This is a personal research project maintained in spare time — issues are triaged in order
of severity and interest, not on a fixed schedule. Before opening an issue, run
`npm run doctor` and include its output; it answers most environment questions.
